Designed for focused work

从代码库到交付。

Grox 把模型、上下文与本地工具放在一个克制的工作区里，让你保持对项目和变更的掌控。

01 / LOCAL

本地工作区

直接选择 Windows 文件夹开始任务。项目文件留在本机，Grox 围绕你的真实代码库工作。

02 / AUTO

完整任务执行

从理解需求到修改文件、运行命令和验证结果，在一个连续的任务流中完成。

03 / SECURE

账号安全连接

使用团队分配的 Grox 账号登录，无需在桌面客户端粘贴或保管底层 API Key。
